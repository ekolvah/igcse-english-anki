# Проект: Anki-колода «английский для IGCSE» для Жени

Своя бесплатная колода Anki из терминов syllabus Cambridge IGCSE Maths 0580, Physics 0625 и Computer Science 0478 для
Жени (английский ~A2): чтобы понимал английские формулировки заданий. Учится на телефоне
(AnkiDroid), компьютер (Anki 26.x) — импорт и статистика. Аккаунт AnkiWeb общий (почта — в
`docs/student.md`, он только на этом компьютере).

## Как общаться
Отвечать **по-русски**, коротко и по делу. Пользователь — родитель, не программист: давать пошаговые
инструкции для Anki/AnkiDroid простыми словами. Бюджета нет — платное не предлагать.
**Импорт колоды в Anki на компьютере и отправку в AnkiWeb агент делает сам** (не просить
пользователя) — порядок в [docs/workflow.md](docs/workflow.md), «Импорт делает агент».

## Где хранить знания (правило пользователя)
**Всё нужное для следующих чатов — только в файлах проекта** (этот файл, `docs/`, README.md,
комментарии в data/*.txt): проект хранится в git и на GitHub, память агента туда не попадает.
**Память агента не использовать.** Когда пользователь просит «запомни» или что-то меняется —
обновлять нужный файл из `docs/` (см. ниже).

## Git и GitHub (правило пользователя, 2026-11-04, 2026-11-15)
Проект — git-репозиторий, ветка `main`, **открытый** репозиторий на GitHub
(https://github.com/ekolvah/igcse-english-anki): там же GitHub Actions каждую ночь строит отчёт.
**После каждого законченного изменения — коммит и `git push`** (данные, скрипты, docs вместе, с
обновлёнными счётчиками), без отдельного вопроса: пользователь попросил, чтобы изменения
сохранялись в git. Сообщение коммита — по-русски, что и зачем. Автор коммитов — служебная почта
GitHub (настроена в `.git/config` проекта), не личная.
**Репозиторий открытый — в файлы под git не писать личное:** почты, пароли и ключи, полное имя
Жени, оценки и баллы, пути `C:\Users\…`, имена личных файлов. Это — только в `docs/student.md`
(в `.gitignore`, лежит только на этом компьютере). Перед коммитом новых docs — проверить.
Что ещё не хранится в git — см. `.gitignore` (собранный `.apkg`, учебники `books/`, PDF, копии
коллекции).

## Документация — что и когда читать
- @docs/requirements.md — как устроены карточки, строгая проверка, что нельзя менять (ID, названия).
  Подключён всегда: нарушать нельзя.
- [docs/status.md](docs/status.md) — **читать в начале работы**: счётчики, последнее изменение,
  что не проверено, следующие шаги. Обновлять после каждого изменения колоды.
- [docs/workflow.md](docs/workflow.md) — перед добавлением слов, сборкой, импортом, запуском
  `anki_settings.py`, работой с коллекцией Anki; окружение.
- [docs/decisions.md](docs/decisions.md) — почему так решено (с датами). Читать, прежде чем
  предлагать изменить правило или настройку; новое решение пользователя — дописать сюда.
- [docs/student.md](docs/student.md) — Женя, его пробник и контрольные, почта AnkiWeb, где лежат
  сканы: при подборе новых слов. **Только на этом компьютере, не в git.**
- [docs/sources.md](docs/sources.md) — что в каком data/*.txt, где учебники и сканы, как их читать.
- [README.md](README.md) — инструкция для пользователя (обновлять счётчики слов/карточек).

## Скилы (`.claude/skills/`)
- `add-words` — добавить слова из нового источника, проверить (`check_words.py`), собрать, обновить docs.
- `zhenya-progress` — отчёт о занятиях Жени по копии коллекции (`progress.py`).
Скилы ссылаются на `docs/`, а не копируют их: правило меняется в `docs/`, шаг — в SKILL.md.
