parallel transmission | параллельная передача | several bits are sent at the same time down several wires | Parallel transmission is used over short distances. |

parity bit | бит чётности | an extra bit added to make the number of 1s odd or even | The parity bit is the first bit of the byte. |

odd parity | нечётный паритет (нечётное число единиц) | the number of 1s in each byte must be an odd number | Using odd parity, 1101 0000 is correct. |
parity byte | байт чётности | an extra byte that holds the column checks for a block of data | A parity byte is sent with the block of data. |

plaintext | исходный текст (до шифрования) | data before it is scrambled | The plaintext is encrypted using a key. |
ciphertext | шифротекст (зашифрованный текст) | data after it has been scrambled | The ciphertext cannot be understood if it is intercepted. |

asymmetric encryption | асимметричное шифрование | uses two different keys: a public one to lock and a private one to unlock | Asymmetric encryption uses a public key and a private key. |
