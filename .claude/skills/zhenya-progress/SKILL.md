# Отчёт о занятиях Жени

1. **Свежие данные.** Женя занимается на телефоне — данные попадают на компьютер только после
   синхронизации. Если пользователь не синхронизировал недавно, попросить: на телефоне
   «Синхронизировать», потом в Anki на компьютере «Синхронизировать».
2. **Запуск** (Anki можно не закрывать — скрипт работает с копией, оригинал не трогает):
   `PYTHONIOENCODING=utf-8 python .claude/skills/zhenya-progress/progress.py --days 7`
   Параметры: `--days N` — период, `--top N` — сколько трудных слов показать.
3. **Как читать:**
   - «Верно» = ответы не «Снова» (оценка ставится карточкой автоматически, см.
     `docs/requirements.md`). «Повторения выученного» ≈ блок «Усвоение» в статистике Anki.
   - Норма из `docs/decisions.md`: ~30 с на карточку, ~40–60 мин/день, 10 + 10 новых.
     **Стабильно > 1 ч в день** — предложить снизить до 8 + 8 (через `anki_settings.py`).
   - Ответы только в одной части (например, Physics = 0) — спросить, не занимался ли Женя с
     подколоды вместо главной «IGCSE English»; проверить пресеты подколод и позиции новых
     (`decks.kind` / `cards.due` в копии коллекции); при сбое — `anki_settings.py` (см. `docs/workflow.md`).
   - После ~1000 ответов всего — предложить оптимизацию FSRS (Настройки колоды → FSRS →
     «Оптимизировать»), пошагово.
   - Трудные слова: если ошибка в одном и том же — посмотреть, не слишком ли строгий/длинный
     вариант ответа в колоде (`ru_accept`). Требование строгой проверки **не смягчать**;
     исправлять можно только сами данные (короче основной вариант, пояснение в скобки) —
     через скил add-words.
4. **Ответ пользователю** — по-русски, коротко: занимался ли каждый день, сколько, % верных,
   динамика, 3–5 трудных слов с переводом, один конкретный совет (если нужен).
5. **Страница-график** https://ekolvah.github.io/igcse-english-anki/ обновляется сама 4 раза в сутки на GitHub
   (`.github/workflows/report.yml`: скачать из AnkiWeb `ankiweb_sync.py` → построить
   `daily_chart.py` по шаблону `chart_template.html` → GitHub Pages), компьютер не нужен.
   Просят «обнови график» — `gh workflow run report.yml`, через 2–3 мин проверить
   `gh run list --workflow report.yml`. Синхронизация на компьютере не нужна — достаточно, чтобы
   Женя синхронизировал телефон. Поломки — в `docs/workflow.md` («Ежедневный отчёт»).
   Тем же запуском обновляется страница **«Слова Жени»** для репетитора
   https://ekolvah.github.io/igcse-english-anki/words.html (`words_page.py` + `words_template.html`):
   все слова со статусом трудные / учит / выучено / впереди, поиск, темы, определение и пример.
   **Запоминает ли он слова** (вопрос «повторяются ли слова всё реже»): на графике панель
   «Запоминает ли он слова» — по дням, сколько начатых карточек Anki спросит через ≤1 / 2–6 /
   7–20 / 21+ дней (`IV_BUCKETS`, по ivl последнего ответа). Растут «7–20» и «21+» — запоминает;
   растёт только «завтра» — те же карточки каждый день. По одному слову — на странице слов
   (раскрыть слово): цепочка интервалов по направлениям, напр. «EN→RU: 1 → 2 → 4 дня — растёт».
   «Выучено» = обе карточки на повторении с интервалом ≥ 7 дней (`LEARNED_DAYS`).
   **Поровну ли по предметам** (страх «учит только математику»): раздел на графике — доли
   математики / физики / информатики среди слов, которые он сейчас учит, и среди ответов за 7 дней,
   столбики новых слов за день по предметам, таблица всего / учит / выучено / впереди.
   Предмет слова — по номеру подколоды (`STREAM_OF_TOP` в `progress.py`).
   **Сколько времени в день**: панель минут по дням — два столбика: карточки и чтение (`rd`, см.
   ниже) — и плитка «в среднем за день занятий» — сумма
   `revlog.time` (время от показа карточки до ответа, Anki обрезает до 60 с на карточку; перерывы
   между карточками не входят — реальное время чуть больше).
   **Новые слова от Жени** (на графике — только минуты чтения, правый столбик «Сколько времени
   в день»: по времени записи слов, правило — docstring `daily_chart.py`): Женя сам пишет незнакомые слова в AnkiDroid,
   колода «Новые слова»; `inbox.py` (в том же ночном запуске) переносит их в
   `data/zhenya_inbox.tsv` со статусом «ждёт». Как обрабатывать — `docs/workflow.md` («Новые
   слова Жени»), карточки делает скил add-words.
6. Если вывод что-то меняет (решили снизить лимит, нашли проблему) — записать в
   `docs/status.md` / `docs/decisions.md`.
