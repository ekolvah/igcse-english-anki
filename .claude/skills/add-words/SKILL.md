# Добавить слова в колоду

Правила карточек и запреты — в `docs/requirements.md` (уже загружен через CLAUDE.md). Где что
лежит и как читать источники — `docs/sources.md`. Сборка и импорт — `docs/workflow.md`.
Здесь только порядок действий; подробности не дублировать, а читать там.

## Шаги

1. **Контекст.** Прочитать `docs/status.md` (что уже сделано) и `docs/sources.md`.
   Для слов из пробника/контрольной — ещё `docs/student.md`.
2. **Источник.**
   - Учебник в `books/` — текст через pypdf (сначала Index, потом частые слова условий задач).
     Новый учебник класть в `books/`.
   - Скан без текста (Downloads) — Read с `pages`, не больше 20 страниц за раз.
   - Слова Жени обрабатываются **сами, ночью на GitHub** (`nightly_prompt.md` + `zhenya_apply.py`).
     Вручную — только если пользователь просит сейчас: `git pull`, `anki_import.py pull`,
     `inbox.py --source desktop`, правила — `nightly_prompt.md`; после импорта — `anki_settings.py`
     (слова Жени — первыми). Порядок — `docs/workflow.md`, «Новые слова Жени».
   - Пробник: искать, где баллы потеряны **из-за языка** (не понял, что просят), а не из-за
     математики/физики — это к учителю.
3. **Отбор.** Брать только термины syllabus 2026–2028 (Maths 0580, Physics 0625, Computer Science 0478); темы вне
   программы пропускать и перечислить в комментарии в начале файла. Приоритет — слова из
   формулировок заданий (command words, «give your answer…», «show that…»).
4. **Новый файл** `data/NN_<источник>.txt` (следующий номер). В начале — комментарий: источник,
   что взято, что сознательно пропущено. Разложить по **существующим** подколодам
   (`## 2 Maths 0580::03 Geometry` — имя точно как в других файлах). Новая подколода — только
   с согласия пользователя. Строка: `term | русский | definition | example | flag`.
   - русский: основной вариант короткий (1–3 слова), пояснения — в скобках или после точки;
   - definition — простой английский (уровень A2), без самого термина и однокоренных;
   - example — фраза в стиле экзаменационного задания;
   - flag `-` — без карточки RU→EN (длинные фразы).
5. **Нельзя:** переименовывать существующие термины или переносить их в другую подколоду
   (GUID = подколода + термин → прогресс потеряется), менять `MODEL_ID`, `DECK_ID_BASE`,
   `GUID_SALT`. Исправлять перевод/определение/пример существующих — можно.
6. **Проверка:**
   `PYTHONIOENCODING=utf-8 python .claude/skills/add-words/check_words.py data/NN_<источник>.txt`
   Разобрать **каждое** `!`: термин уже есть (в любом предмете) — не добавлять, другое значение
   дописать в существующую строку («…; in physics — …»); слово из скобок как ответ —
   решить, верно ли; подсказка выдаёт ответ — переписать определение; длинный основной вариант —
   укоротить. Повторять, пока не останутся только осознанные предупреждения.
7. **Сборка:** `PYTHONIOENCODING=utf-8 python build_deck.py` — проверить, что нет
   «дубликат пропущен» по новым словам и счётчики выросли на ожидаемое число.
8. **Документация:** обновить счётчики в `README.md`, `docs/status.md` (что добавлено, итоги),
   строку про новый файл в `docs/sources.md`; новое решение пользователя — в `docs/decisions.md`.
9. **Импорт — делает агент сам**, пользователя не просить (его решение 2026-11-13):
   `anki_import.py` pull → import → (`anki_settings.py`, если новая подколода) → push → проверка
   `ankiweb_sync.py`. Порядок и условия — `docs/workflow.md`, «Импорт делает агент».
   Если Anki на компьютере открыт — попросить только закрыть его. Если скрипт остановился
   (несинхронизированные изменения, требуется полная синхронизация) — ничего не форсировать,
   объяснить пользователю и спросить.
   **Пользователю** — только: синхронизировать телефон (AnkiDroid, круглые стрелки), сколько слов
   добавлено и из какого источника.
10. **Коммит** (правило в CLAUDE.md): `git add -A && git commit` — data, docs, README вместе;
    сообщение по-русски: «Слова из <источник>: +N терминов (…)», затем `git push` (CLAUDE.md).
