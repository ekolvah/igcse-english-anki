Ты работаешь ночью на сервере GitHub, без человека. Проект — колода Anki «английский для IGCSE»
для школьника Жени (английский ~A2). Женя сам записал в Anki незнакомые слова из учебников IGCSE.
Твоя задача — превратить каждое слово со статусом «ждёт» в строку колоды. Сборку, проверку,
импорт и отправку в Anki потом делает скрипт `zhenya_apply.py`, не ты.

## Прочитай
- `docs/requirements.md` — правила карточек (особенно «Одно слово — одна карточка» и «Какие ответы
  засчитываются»).
- `.claude/skills/add-words/SKILL.md`, шаги 3–6 — как писать строку и проверять её.
- `data/zhenya_inbox.tsv` — слова. Колонки через табуляцию: id, day, word, context, status,
  result, term. `context` — где Женя встретил слово.

## Для каждой строки со статусом «ждёт»
Определи, какой термин Женя имел в виду: исправь очевидную опечатку, приведи к словарной форме
(«transfers» → «transfer»). Если слово в context входит в устойчивое выражение из экзаменационных
формулировок, можно взять выражение. Затем найди термин во всех `data/*.txt` (первое поле до `|`,
без учёта регистра; проверь и однокоренные).

1. **Термин уже есть в колоде** — ничего не добавляй.
   В строке tsv поставь `status` = `уже было`, `term` = термин точно как в data-файле (первое
   поле), `result` = `уже в колоде: <русский перевод> (<предмет>)`.
   Если у термина в колоде другое значение, чем в context Жени, допиши это значение в
   существующую строку («…; in physics — …»). Сам термин не меняй.
2. **Термина нет** — допиши строку в конец `data/10_zhenya_words.txt` под заголовком нужной
   подколоды `## <подколода>`. Если такого заголовка в файле ещё нет, добавь его. Имя подколоды
   бери точно из заголовков других `data/*.txt`. Новых подколод не придумывай.
   Предмет выбирай по context и смыслу: Maths 0580, Physics 0625 или Computer Science 0478.
   Общие слова формулировок заданий кладутся в «Question language» своего предмета:
   `## 0 Maths question language::Words in word problems` или
   `## 5 Computer Science 0478::00 Question language`. Для физики — подходящая тема
   `## 3 Physics 0625::…`.
   Формат строки: `term | русский | definition | example |`. Правила:
   - русский — короткий основной вариант, 1–3 слова; пояснения — в скобках;
   - definition — простой английский A2, без самого термина и однокоренных;
   - example — фраза в стиле задания IGCSE; можно взять context Жени.
   В tsv поставь `status` = `добавлено`, `term` = термин из новой строки,
   `result` = `<русский основной вариант> → <подколода без номера темы>`.
3. **Не понять, что за слово** (не английское, бессмыслица, опечатку не восстановить) — поставь
   `status` = `непонятно`, а в `result` по-русски коротко напиши, почему. Остальное не трогай.
   Женя увидит причину и исправит слово.

## Потом
- Запусти
  `python .claude/skills/add-words/check_words.py data/10_zhenya_words.txt`.
  Разбери каждое `!` по шагу 6 SKILL.md. Термин уже есть — убери свою строку и сделай для
  слова случай 1. Подсказка выдаёт ответ — перепиши definition. Повторяй, пока не останутся
  только осознанные предупреждения.
- tsv редактируй аккуратно: одна строка на слово, ровно 7 колонок через табуляцию, без
  переносов внутри. Пустые колонки в конце строки можно не дописывать — они читаются как пустые,
  исправлять это не нужно. Не меняй колонки id, day, word, context. Не трогай строки с другими
  статусами.
- Не переименовывай и не переноси существующие термины. Не меняй другие файлы, кроме
  `data/*.txt` и `data/zhenya_inbox.tsv`. Ничего не запускай, кроме check_words.py.
- В конце одной строкой выведи, что сделано: сколько слов добавлено, сколько уже было,
  сколько непонятно.
