# Колода Anki: английский для IGCSE Maths 0580, Physics 0625 и Computer Science 0478

Файл для импорта: **IGCSE_Maths_Physics.apkg** (1481 слово, 2951 карточка).

Слова взяты из официальных Cambridge syllabus: Mathematics 0580 (2025–2027), Physics 0625 (2026–2028) и Computer Science 0478 (2026–2028), уровни Core и Extended/Supplement. Дополнены недостающими терминами из учебников Hodder (Maths 2018, Physics 2014; лежат в папке `books/`). Подколода 0 составлена по рабочей тетради учителя математики «Understanding maths questions» (Core mock 0580/11).

## Что внутри

| Подколода | Что там |
|---|---|
| 0 Maths question language | язык условий задач из тетради учителя: форма ответа (as a fraction, in terms of n), короткие слова (less than / at most / at least, but not), слова из текстовых задач (each, every, together, the next time), графики и построения (x-intercept, using a ruler and compasses only). **From October mock**: формулировки из пробного экзамена, на которых Женя потерял баллы (type of correlation, modal class, geometrical reason, describe fully, interest earned, n(A)…) |
| 1 Command words | глаголы из заданий (describe, explain, state, show that…) с официальными определениями Cambridge и экзаменационные инструкции (hence, exact value, 3 s.f.…) |
| 2 Maths 0580 | 8 тем: Number, Algebra, Geometry, Mensuration, Trigonometry, Transformations, Probability, Statistics |
| 3 Physics 0625 | практические навыки и оборудование + 6 тем из syllabus (плюс слова из учебника Hodder Physics: steady speed, from rest, Hooke's law, stopping distance, filament lamp, mains, appliance, opaque, tracer…) |
| 4 Answer phrases | готовые фразы для письменных ответов по физике (as X increases…, so / therefore…) |
| 5 Computer Science 0478 | информатика: язык заданий (tick one box, complete the paragraph, use the terms from the list, benefit / drawback…) + 10 тем syllabus (binary, packet, CPU, register, compiler, phishing, flowchart, trace table, array, primary key, logic gate…); формулировки — из экзаменов 0478 2024 года |

Типы карточек. **В обеих ответ нужно напечатать**, просто посмотреть не получится:
1. **EN → RU**: показано английское слово, оно произносится вслух (британский TTS телефона). Нужно напечатать перевод по-русски. На обороте полный перевод, простое английское определение и пример.
2. **RU → EN**: показаны перевод и английское определение, в котором само слово скрыто (`___`). Нужно напечатать слово по-английски. Делается для всех слов, кроме длинных шаблонов с «…» и длинных фраз-инструкций.

На обороте карточка сама проверяет ответ и **сама ставит оценку**: внизу карточки появляется кнопка «Дальше →».

Ответ засчитывается, **только если он точно совпадает** с одним из вариантов перевода в колоде (варианты записаны через запятую, например «вместимость, ёмкость»). Не важны только заглавные буквы, ё/е, знаки препинания и лишние пробелы. Другое окончание, опечатка или синоним, которого нет в колоде, считаются ошибкой.

| Надпись | Кнопка «Дальше» ставит |
|---|---|
| ✅ Верно | Хорошо (слово будет показываться всё реже) |
| ❌ Ошибка в одной букве / Неверно / Ответ не написан | Снова (слово повторится скоро) |

Стандартные кнопки Anki внизу экрана остаются, но нажимать их не нужно. На компьютере не нажимайте Enter второй раз: Enter на обороте ставит «Хорошо» без проверки.

## Процент правильных ответов

Оценка ставится автоматически: «Снова» = неверно, «Хорошо» = верно. Готовой строки «правильно N» в Anki нет: **правильные = всего − «Снова»**. Где смотреть: **Статистика** (на телефоне ☰ → Статистика, на компьютере кнопка «Статистика»), выбрать колоду IGCSE English:
- **Сегодня**: «Сегодня 3 карточки… Количество «Снова»: 1 (33,33%)» → неверно 1, верно 2 из 3 = 67%;
- **Кнопки ответа**: красный столбик = неверные, зелёный = верные (наведите на столбик — покажет число и %);
- **По часам**: линия — процент правильных;
- **Усвоение**: процент верных среди слов, которые повторяются через день и больше («Сегодня / Вчера / На прошлой неделе / В прошлом месяце»). Это главный показатель, что слова реально запомнились; первые дни там N/A — это нормально.

Цифры честные, если переходить дальше кнопкой «Дальше» на карточке.

**График по дням** (процент верных, время, предметы, запоминание): https://ekolvah.github.io/igcse-english-anki/ — обновляется сам каждую ночь из AnkiWeb (к 6 утра по Кипру), компьютер может быть выключен. Жене достаточно синхронизировать телефон. Не обновился — откройте Claude в этой папке и напишите «обнови график».

На графике «Сколько времени в день» у каждого дня два столбика: минуты над карточками и минуты
чтения (наведите на день — видно, во сколько он читал и какие слова записал). Что сделано с каждым
словом Жени (добавлено в колоду, уже было, ждёт) — в файле `data/zhenya_inbox.tsv` на GitHub.
Время чтения — оценка: пока Женя читает, он записывает слова; если больше 30 минут не записывал —
считается, что перестал читать (сеанс — от первого до последнего слова, одно слово — 5 минут).

**Список слов для репетитора**: https://ekolvah.github.io/igcse-english-anki/words.html — все слова колоды: трудные, которые учит сейчас, выученные и те, что ещё впереди; поиск, темы, определение и пример по нажатию. Обновляется вместе с графиком. Открывается по ссылке у всех, входить никуда не нужно.

## Как поставить на телефон (AnkiDroid)

1. Скопировать `IGCSE_Maths_Physics.apkg` на телефон: через Telegram, Google Drive или кабель.
2. Открыть файл на телефоне → «Открыть с помощью AnkiDroid» → импорт.
   Или в AnkiDroid: ⋮ → Импорт → выбрать файл.
3. Если слова не звучат: в настройках Android поставить «Синтезатор речи Google» и скачать английский (UK) голос.

## Как заниматься

- **Математика, физика и информатика идут параллельно**, у каждой свой набор настроек:
  - «Maths» — подколоды 0 Maths question language, 1 Command words, 2 Maths 0580;
  - «Physics» — подколоды 3 Physics 0625, 4 Answer phrases (Physics);
  - «Computer Science» — подколода 5 Computer Science 0478;
  - в каждом: **10 новых в день**, максимальный интервал **60 дней** (чтобы каждое слово всплыло до экзамена хотя бы раз в 2 месяца), порог пиявки 5;
  - у главной колоды «IGCSE English» («По умолчанию»): 20 новых, 300 повторений — это общий потолок, он должен быть не меньше суммы;
  - новые карточки идут вперемешку: слово из Maths, слово из Physics, слово из Computer Science… Сначала язык заданий (формулировки, command words, answer phrases), потом темы;
  - всё это ставит скрипт `anki_settings.py` (руками в настройках менять не нужно). После импорта новых слов запускать его уже не нужно: порядок слов задаёт сам файл колоды. Нужен, только если появилась новая подколода — Claude запускает его сам при импорте.
  - Заниматься — нажимая главную колоду **«IGCSE English»**, а не подколоды: иначе будет только одна часть (например, без Physics).
- **20 новых карточек в день ≈ 10 новых слов** (у слова 2 карточки, вторая придёт на следующий день): примерно по 7 из каждого предмета. Так вся колода (1481 слово) пройдена примерно за 5 месяцев. Время — около 40–60 минут в день, когда накопятся повторения. Если стабильно больше часа — снизить до 8 + 8.
- Включены **FSRS** и в разделе «Скрытие» **«Скрывать связанные новые» и «Скрывать связанные повторения»**, чтобы обе карточки одного слова (EN→RU и RU→EN) не шли в один день.
- Трудные слова: на компьютере «Список» → поиск `tag:leech` — список слов с 5+ ошибками (показать учителю).
- На телефоне держать на клавиатуре два языка (русский и английский) и переключать их кнопкой 🌐.
- Каждый день, хотя бы немного. Пропустить три дня хуже, чем делать по 5 минут.
- Хорошо работает связка с репетитором: дать ему список тем из этой колоды, чтобы он использовал эти слова на уроках.

## Женя записывает незнакомое слово сам

Встретил в учебнике незнакомое слово — записать его в AnkiDroid, в колоду «Новые слова»:
1. AnkiDroid → кнопка **«+»** → **«Добавить»**.
2. Вверху: тип **«Простая»**, колода **«Новые слова»**. «Лицевая сторона» — слово, «Оборотная
   сторона» — предложение, где оно встретилось (можно пусто).
3. Нажать **✓**, потом **«Синхронизировать»** (круговые стрелки).

Быстрее: в учебнике или браузере выделить слово → «Поделиться» → AnkiDroid.

На саму колоду «Новые слова» нажимать не нужно: пока она пустая, AnkiDroid предлагает добавить
карточку, но как только в ней есть хоть одно слово, открывается экран «Congratulations! You have
finished this deck for now… daily limit has been reached». Это не ошибка (учить там нечего,
лимит 0) — нажать стрелку «←» и добавить слово через **«+»** на главном экране.
Учить в колоде «Новые слова» нечего — она только для записи. Ночью Claude сам сделает из слова
карточку (или найдёт, что оно уже есть в колоде) и поставит его **первым** среди новых: утром
синхронизировать телефон — и слово уже в занятиях. На странице графика видно, что сделано с каждым
словом. Если слово не понято (опечатка), оно останется в «Новых словах» с причиной на странице —
исправить его там же.

## Как добавить свои слова

Слова лежат в текстовых файлах в папке `data/`. Одна строка — одно слово:

```
term | русский перевод | простое определение по-английски | пример |
```

- Последние три поля можно оставить пустыми, например `velocity | скорость (векторная) | | |`.
- При вводе засчитываются только варианты перевода до точки, тире или двоеточия. Синонимы пишутся через запятую: `плотность, удельная масса`. Пояснения пишутся в скобках или после точки, например `ток (I)` или `описать (ЧТО происходит). Не объяснять «почему»!`.
- `-` в последнем поле означает: не делать карточку RU → EN (для очень длинных фраз). Старый `+` больше ничего не значит.
- Строка `## 3 Physics 0625::03 Waves` начинает подколоду.
- Можно создать новый файл, например `data/08_from_tutor.txt` со словами от репетитора или из глоссария учебника.

Пересобрать колоду (нужен Python и `pip install genanki`):

```
python build_deck.py
```

Новые слова в Anki на компьютере и в AnkiWeb загружает Claude сам — после этого достаточно синхронизировать телефон. Если импортировать вручную: новый `.apkg` импортировать поверх старого: исправленные слова обновятся, **прогресс сохранится**. Не переименовывайте термин или подколоду у уже изученных слов: Anki сочтёт это новой карточкой.
